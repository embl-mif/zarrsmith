   Keep old ``is_label=True`` calls working by dropping an image C axis.

   New callers can request channelled labels explicitly with
   ``data_type='label'`` and metadata whose axes include ``c``.  Old ZarrSmith
   examples passed the intensity image metadata plus ``is_label=True``; those
   should still create ``tzyx`` labels.


.. py:function:: create_empty_group(root: zarr.Group, group_name: str, metadata: dict[str, Any], is_label: bool = False, ngff_version: str | None = None, zarr_format: int | None = None, compressor: str | None = None, compressor_level: int = DEFAULT_COMPRESSOR_LEVEL, data_type: str | None = None, shards: Any = None, shard_target_mb: float = 1024.0, shard_exclude_axes: Any = None, overwrite: bool = False)

   Create an empty image subgroup or label subgroup inside an existing root.

   The subgroup inherits the root NGFF/zarr version so the hierarchy stays
   internally consistent. When ``is_label`` is ``True`` the group is created
   below ``labels/`` and the root label registry is updated. An existing group
   of that name raises ``FileExistsError`` unless ``overwrite`` is ``True``, which
   deletes it with a warning; an array (such as a pyramid level) is never replaced.
