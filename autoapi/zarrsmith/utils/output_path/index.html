zarrsmith.utils.output_path.output_refusal(path: str | pathlib.Path, *, overwrite: bool = False, sources: Iterable[Any] = (), hint: str = 'pass overwrite=True') → str | None[source]

Why path must not be written to, or None if it can be.

A missing path or an empty folder can always be written to. An existing Zarr store needs overwrite. Files and non-empty folders that are not Zarr stores are never replaced, because writing with overwrite first deletes everything in the output folder.

sources are the paths the data is read from (None entries are ignored): the output cannot be one of them or contain one, and cannot be inside a source that is a Zarr store. Reading is lazy, so replacing a source loses the data. hint says how to allow overwriting, in the terms of the caller.
