zarrsmith.utils.czi.read_block_index(path, dtype) → Dict[Tuple[Tuple[str, int], ...], CziBlock][source]

{block_key(coordinates): CziBlock} of the planes read_block() can read.

Only the directory of the file is read. Planes that have to go through aicspylibczi are left out: other compressions (e.g. JPEG XR), pixel types other than dtype, planes stored in another part of a file split in several, and planes that share their coordinates. Pyramid levels stored in the file are left out too.
