zarrsmith.utils.resample

Resample a dataset to a new pixel size.

Every output pixel i samples the input at i * factor, with factor = new pixel size / old pixel size. The grid is global, so the result does not depend on the chunking or on the batches, and index 0 stays in place: this is the convention of the pyramid builder, and the output overlays the input in a viewer.

resample_levels() is lazy and suits data that fit in one dask graph. write_resampled() scales to large stores: it computes one batch at a time, so the graph and the memory depend on the batch and not on the dataset.

Sample block along axis at the (fractional) positions coords.

The triangular kernel spans width input pixels on each side: with a width of 1 this is linear interpolation, and wider it averages all the input pixels under a new one (anti-aliasing), computed only at the output positions.

factors must come from _effective_factors(), and region holds one slice per axis, in output pixels. Output blocks are multiples of chunks from the start of the region. Only the input under the region is read.

Resample arr, given {axis index: new pixel size / old pixel size}.

Linear interpolation, anti-aliased on the axes that shrink, or nearest neighbour with nearest=True. Output chunks are chunks (default: those of arr), except when a small chunk cannot hold the overlap on its own.

The coarsest level at least as fine as target on every axis, or level 0.

Pyramid levels are usually built by skipping pixels, so an image read from one keeps its aliasing: only labels, or a request for speed, should use them.

zarrsmith.utils.resample.resample_levels(data: collections.abc.Sequence[dask.array.Array], metadata: dict[str, Any], target_scale: float | collections.abc.Sequence[float] | collections.abc.Mapping[str, float], *, fast: bool = False) → tuple[list[dask.array.Array], dict[str, Any]][source]

Lazily resample a dataset to target_scale and rebuild its pyramid.

target_scale is the new pixel size in the units of the dataset: one value, one per spatial axis, or a dict such as {"z": 1.0} (omitted axes are kept).

Labels use nearest neighbour and images linear interpolation. Images are read from level 0 unless fast, which reads the coarsest level still fine enough: much less data, but it keeps the aliasing of that level. Labels always do this. The number of levels is preserved.

zarrsmith.utils.resample._batches(shape: collections.abc.Sequence[int], block: collections.abc.Sequence[int], max_pixels: float) → collections.abc.Iterator[tuple[slice, ...]][source]

Split an output array into regions of at most max_pixels, computed in turn.

Regions stay as large as allowed, because only the blocks of one region run in parallel: axes are split in array order (usually t first) and only as far as needed. Regions are whole blocks, so two of them never share a shard.

zarrsmith.utils.resample._fitted_array_kwargs(src: zarr.Array, shape: collections.abc.Sequence[int]) → dict[str, Any][source]

create_array keywords of src, with chunks and shards fitted to shape.

Zarr stores every chunk in full, so a chunk reaching past the end of the array stores padding, which takes real space when uncompressed. Chunks therefore divide each axis evenly, and neither they nor the shards outgrow the input’s or the array.

zarrsmith.utils.resample.write_resampled(source_root: zarr.Group, datasets: collections.abc.Sequence[tuple[str, Any]], path: str | pathlib.Path, target_scale: float | collections.abc.Sequence[float] | collections.abc.Mapping[str, float], *, fast: bool = False, overwrite: bool = False, num_workers: int | None = None, progress: bool = True) → zarr.Group[source]

Write a copy of an OME-Zarr store with a new pixel size.

datasets are (name, dataset) pairs as yielded by ZarrManager._iter_datasets. Every array copies the codecs and attributes of its source, with chunks and shards fitted to its new shape (see _fitted_array_kwargs()), and every group its attributes. Level 0 is resampled first (see resample_levels() for target_scale and fast) and every other level is built from the level below it, read back from the output, keeping the downscale factors of the input.
