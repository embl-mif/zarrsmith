class zarrsmith.mosaic_manager.zeiss_mosaic_manager.ZeissMosaicManager(path, scene_index: int | None = None)[source]

Bases: zarrsmith.mosaic_manager.mosaic.MosaicManager

Raw Zeiss tiles of one .czi file (a ZEN tile scan), before any stitching.

Not to be confused with ZeissManager, which reads one scene as a single image; a file without tiles, such as the output of ZEN’s Stitching, is read with it. Every tile (M index) of every channel and timepoint is one tile, and its planes stay on disk until read (CziTileArray).

  • channel: the channel name in the metadata (AF488-T2);

  • field: the scene: scene0_TR1, scene1_P1, … with the tile regions and positions of the ZEN experiment as TR1 and P1;

  • timepoint: the T index;

  • attrs: stack (scene0_TR1-m00, the tile id without the channel), scene, scene_name, mosaic_index and path.

Tiles are placed where the file says: y and x from the pixel coordinates of the tile in the file (the stage position, rounded to a pixel), z from the FocusPosition of its first plane. They are not registered, unlike the images stitched by ZEN. Positions in the file change a little between timepoints: by default a fusion uses those of one reference timepoint, as ZEN uses one offset for all; reference_timepoint="all" uses those of every timepoint.
