class zarrsmith.mosaic_manager.mosaic.MosaicManager(path: str | pathlib.Path)[source]

Bases: abc.ABC

A set of separately acquired, positioned tiles (not yet one image).

Unlike a MicroscopeManager, which wraps one image, a mosaic exposes the raw tiles lazily and fuses them on request with fuse(). Subclasses implement _scan() only.

Mosaics can be used as context managers so that open file handles are closed:

with mosaic_manager.LuxendoMosaicManager("raw_folder") as mosaic:
    mosaic.fuse("overview.ome.zarr", ds=(4, 8, 8), projection="max")

When loaded, every tile is labelled with the field it belongs to: tiles whose boxes overlap or touch form one field (a connected component), named field0, field1, … by position (see fields). fuse() fuses the first field by default; pick another with mosaic.fuse(out, field="field1"). Tiles of several fields are never fused together: that raises a MultipleFieldsError.

A mosaic can hold several timepoints (timepoints): tiles then has the tiles of all of them. fuse() places every timepoint with the geometry of one reference timepoint and visualize() adds a time slider.

tile_id(tile: zarrsmith.mosaic_manager.tile.Tile) → str[source]

Stable name of a tile, "<channel>/<stack>" (e.g. "cFos-647/1-x00-y00"), or "<channel>/<stack>/<camera>" ("DAPI/0-x00-y00/right") when the mosaic has several cameras.

<stack> is the reader’s stack name (attrs["stack"]) or, without one, the index of the earliest tile at that position. The tiles of a position share their id at every timepoint. Used to skip tiles from the command line or a batch CSV.

classmethod _lazy_series(series: Dict[int, zarrsmith.mosaic_manager.tile.Tile], timepoints: Sequence[int]) → Tuple[dask.array.Array, Tuple[float, ...], Dict[int, Tuple[int, ...]]][source]

(t, z, y, x) array of the tiles of one position over timepoints, read lazily.

The array covers every place the tile reaches, and every timepoint holds the tile at its own position, rounded to a voxel, with zeros around it (which read nothing). A timepoint without a tile, or whose tile has another shape than the earliest one, is shown as zeros.

Returns the array, the position of its first voxel and, per timepoint with a tile, the (z, y, x) voxel where the tile starts.

contrast_limits(tiles: Sequence[zarrsmith.mosaic_manager.tile.Tile] | None = None, n_tiles: int = 6, block: int = 64, percentiles: Tuple[float, float] = (0.5, 99.9)) → Dict[str, Tuple[float, float]][source]

Display range of every channel, estimated from a small sample.

For each channel, one block-sized cube is read from the centre of up to n_tiles tiles (about 0.5 MB each for uint16 and block=64, the HDF5 chunk size of Luxendo tiles), and the given percentiles of those voxels are returned as (low, high). The sampled tiles are the ones closest to the centre of each tile group (e.g. each illumination side), where the sample usually is; edge tiles often only show background. Only the earliest timepoint of every position is sampled.

visualize(tiles: Sequence[zarrsmith.mosaic_manager.tile.Tile] | None = None, viewer: napari.Viewer | None = None, contrast_limits: str | Dict[str, Tuple[float, float]] | None = 'range')[source]

Show tiles in napari, each as its own layer at its stage position.

One colour per channel and additive blending, so overlaps and gaps are easy to see. Data stays lazy: only the planes napari displays are read. All tiles of a channel share one contrast setting, and their layers are linked: changing the contrast or gamma of one tile changes all of them.

When tiles span several timepoints, each position is one (t, z, y, x) layer in which the tile sits at its stage position of that timepoint, rounded to a voxel, so it moves as the napari slider scrolls through time, starting on the first timepoint. The layer covers every place the tile reaches. Slider step i is the i-th of the timepoints shown. Only the planes displayed at the current timepoint are read.

Parameters

tiles

Tiles to show (default: all), e.g. mosaic.select(channel="cFos-647"). Every displayed plane reads whole HDF5 chunks of every tile, so showing fewer tiles keeps napari responsive.

viewer

Viewer to add the layers to; a new one is created by default.

contrast_limits

"range" (default) uses the whole range of the data type (0 to 65535 for uint16), which reads nothing: set the contrast of one tile and the linked tiles follow. "auto" estimates it per channel with contrast_limits() (reads a small sample, slow on network drives); a {channel: (low, high)} dict uses those, with the whole range for the channels it leaves out; None lets napari compute them per tile (slow on large tiles).

fusion_tiles(tiles: Sequence[Tile | str] | None = None, field: str | Sequence[str] | None = None) → List[zarrsmith.mosaic_manager.tile.Tile][source]

The tiles a fusion uses: tiles (default: all) restricted to field.

tiles are Tile objects or ids accepted by tiles_by_ids(); field is one field name or a list of them (see field_tiles()). Without tiles and field, the tiles of the first field. The tiles keep the mosaic order. Tiles of several fields are returned as asked, but fuse_tiles() refuses them. Tile ids and fields name the tiles of every timepoint.

fuse(out: str | pathlib.Path, tiles: Sequence[Tile | str] | None = None, field: str | Sequence[str] | None = None, skip: Sequence[Tile | str] | None = None, **kwargs)[source]

Fuse tiles into an OME-Zarr image; see fuse_tiles().

Parameters

out

Output .ome.zarr path.

tiles

Only fuse these tiles, as Tile objects or ids accepted by tiles_by_ids() ("cFos-647/1-x00-y00", or "1-x00-y00" for every channel). The output fits them.

field

Only fuse the tiles of this field ("field1"); combined with tiles, only the given tiles of that field. The output fits the field. Without tiles and field, the first field (fields) is fused.

skip

Tiles to leave blank (same forms as tiles): they are not read, but the output keeps the size and position it has with them. An id blanks that position at every timepoint, a Tile only at its own timepoint.

**kwargs

Options of fuse_tiles(), among them timepoints and reference_timepoint for a mosaic with several timepoints (reference_timepoint="all" places each at its own stage positions).

Tiles of more than one field are not fused: a MultipleFieldsError is raised.

apply_transforms(transforms) → Dict[str, Any][source]

Place the tiles with the positions of a transforms file instead of the stage positions.

transforms is a path to a JSON file written by a fusion (see transforms_document()) or that document as a dict. Every listed tile (matched by tile_id() and timepoint) gets the listed translation as its origin and the listed flip, in place. Tiles that are not listed keep their stage positions. Returns the document.
