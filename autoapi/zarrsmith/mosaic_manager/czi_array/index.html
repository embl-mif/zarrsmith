Lazy, picklable (z, y, x) stack of one tile of a CZI file.

Like H5Array, it holds no open file, so it can be sent to worker processes and needs no close(). CZI planes are stored whole, so slicing reads only the planes it needs, each one in full.

Parameters

path

The .czi file.

coords

Coordinates of the tile in the file, without Z, e.g. {"S": 0, "T": 1, "C": 2, "M": 1}.

planes

Z index in the file of every plane, in order. None marks a missing plane, read as zeros.

shape, dtype

(z, y, x) shape and data type, from the metadata (no plane is read).

blocks

Where every plane is stored (read_block_index()), to read it directly. A plane without one is read with aicspylibczi, which goes through the whole directory of the file: seconds per plane if it holds a million subblocks.
